#
# Source anchors, with the interpolated `${...}` slots redacted so only
# the constant "route" parts remain -- those are what the downstream
# const-ratio ranking (see demo/formbricks.md, Task G) uses to score
# URL-emitting handlers:
#
#     181  `... /api/v1/client/ ... /storage/local`               -- H2' private
#     182  `... /api/v1/management/storage/local`                 -- H2 public
#     189  `... /storage/ ... / ... / ... `                       -- fileUrl (local)
#     208  `... /storage/ ... / ... / ... `                       -- fileUrl (S3)
#
# The parser side that emits these facts is a three-part change:
#
#   1. `parser.ts` in the frontts service adds explicit handlers for
#      `ts.SyntaxKind.TemplateHead` / `TemplateMiddle` / `TemplateTail` /
#      `NoSubstitutionTemplateLiteral`. The default branch would drop
#      the constant text ( these nodes have no AST children ), so the
#      handlers pull `.text` and emit it as a STR-token payload -- the
#      cooked-text-in-parens shape the Happy grammar's `templateHead`,
#      `templateMiddle`, `lastTemplateToken`, and `exp_template_token`
#      rules consume.
#
#   2. `TsParser.y` updates those four productions to actually read the
#      STR payload (instead of returning `Nothing`), and rewires
#      `template_span` to return a 2-element list `[interpolatedExp,
#      literalSuffixExpStr]`. The `fstring` production is retargeted
#      onto the new `Actions.fstring` smart constructor.
#
#   3. `TsParserActions.hs` adds `constStrExp` helper and rewires
#      `fstring` to wrap the head expression plus every span's
#      `[interpolatedExp, literalSuffixExpStr]` pair as an interleaved
#      argument list to `instrumentationCall "fstring"`. The interleaving
#      is what preserves the const/dynamic distinction so kbgen can
#      emit `kb_const_string` for the literal segments while still
#      routing the interpolated slots through the normal dataflow graph.
#
# If ANY of those three parts regresses ( for example the frontts image
# gets rebuilt from a pre-fix parser.ts, or the `constStrExp` helper
# gets dropped, or the grammar rules revert to their `Nothing` result
# form ), the const-string facts below will not appear in the KB and
# this CI step will fail.
#
